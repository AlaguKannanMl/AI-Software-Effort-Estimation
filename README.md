# AI-Based Software Effort Estimation

## Project Description
This project uses Machine Learning to estimate software development effort based on project characteristics.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Machine Learning Model
Random Forest Regression

## Input Features
- Team Experience
- Manager Experience
- Year End
- Project Length
- Transactions
- Entities
- Points Non-Adjusted
- Adjustment
- Points Adjusted
- Programming Language

## Output
Estimated Software Development Effort in person-hours.

## Application
A Streamlit web application is used to enter project details and generate the estimated software effort.
